<details>
<summary><b>🎞️ Extended Cut — SunSync UV Tanning Utility</b></summary>
<br/>

A precision weather tool that bridges the gap between atmospheric data and skin safety.
- **Core Logic:** Real-time UV Index parsing for exposure window calculation.
- **User Focus:** Mobile-first design featuring custom tanning timers based on skin phototypes.
</details>

<details>
<summary><b>🎞️ Extended Cut — iMathAS Gradebook Tracker Enhanced</b></summary>
<br/>

A browser-side injection tool to enhance native university portal capabilities.
- **Functionality:** Injects deadline countdowns and "What-If" grade projection models directly into the UI.
- **Tech:** Advanced DOM manipulation and local storage persistence.
</details>

<details>
<summary><b>🎞️ Extended Cut — Humanized Stealth Auto-Clicker</b></summary>
<br/>

A low-level system utility focused on anti-detection and organic interaction.
- **Humanization:** Implements Gaussian-distributed delays and micro-jitter coordinates.
- **Integration:** Leverages **Quartz Event Services** to interface with the macOS window server.
</details>
